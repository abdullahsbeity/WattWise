# Flutter Sample Project

This is a small Flutter sample application prepared for the CSCI410 Mobile Application Project 1 proposal requirement.

## Purpose

- Demonstrates a basic Flutter project structure.
- Contains one simple screen.
- Includes a working button and SnackBar.
- Uses no database, backend, API, or internet connection.

## Run locally

1. Install Flutter and set up an emulator or connect an Android device.
2. Open this folder in VS Code or Android Studio.
3. Run:

```bash
flutter pub get
flutter run
```

## Note

This is only a GitHub sample project for the proposal stage. It is not the completed WattWise application.
